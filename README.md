# company-intro-
이모부 회사 소개 사이트 제작

화장실 칸막이 시공 전문업체 소개용 반응형 홈페이지 시안입니다. 빌드 도구 없이 `index.html`을 바로 열면 됩니다.

## 구성
- `index.html` — 데모 첫 화면 (A안 / B안 선택)
- `a/` — **A안 · 모던 카드형**: 히어로 / 실적 / 강점 / 시공품목 / 시공사례 / 시공절차 / 시공지역 / FAQ / 견적문의
- `b/` — **B안 · 원페이지 나열형**: 01~08 번호 섹션 (회사소개 / 시공품목 / 자재비교 / 시공사례 / 시공절차 / 시공지역 / FAQ / 견적문의)
- `assets/` — 선택 화면용 미리보기 이미지
- 각 안의 `css/style.css` 상단 `:root` 변수에서 색상 변경

시안이 확정되면 해당 폴더 내용을 최상위로 옮기고 `index.html`(선택 화면)과 `.demo-back` 버튼을 지우면 됩니다.

## 실제 정보로 바꿔야 할 항목
- 상호 `한결칸막이`(임시), 대표자명, 사업자등록번호, 주소
- 전화번호 `010-0000-0000`, 이메일 `contact@example.com`
- 실적 수치(경력·현장 수 등), 시공 사례 이미지(현재 일러스트 자리표시)
- 문의폼은 현재 화면 표시만 됩니다. 실제 접수를 받으려면 Formspree 등 폼 서비스나 이메일 연동이 필요합니다.
