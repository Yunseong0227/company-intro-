# company-intro-
이모부 회사 소개 사이트 제작

화장실 칸막이 시공 전문업체 소개용 반응형 원페이지 홈페이지입니다. (빌드 도구 없이 `index.html`을 바로 열면 됩니다.)

## 구성
- `index.html` — 헤더 / 히어로 / 실적 / 강점 / 시공품목 / 시공사례 / 시공절차 / 시공지역 / FAQ / 견적문의 / 푸터
- `css/style.css` — 스타일 (색상은 상단 `:root` 변수에서 변경)
- `js/main.js` — 모바일 메뉴, 스크롤 애니메이션, 숫자 카운트, 문의폼 검증

## 실제 정보로 바꿔야 할 항목
- 상호 `한결칸막이`(임시), 대표자명, 사업자등록번호, 주소
- 전화번호 `010-0000-0000`, 이메일 `contact@example.com`
- 실적 수치(경력·현장 수 등), 시공 사례 이미지(현재 일러스트 자리표시)
- 문의폼은 현재 화면 표시만 됩니다. 실제 접수를 받으려면 Formspree 등 폼 서비스나 이메일 연동이 필요합니다.
